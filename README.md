# StackHand

Downloads for StackHand for Mac.

- **Download the latest version:** see [Releases](../../releases/latest), then download `StackHand.zip`.
- **Requirements:** a Mac with Apple Silicon, running macOS 13 or later.
- **Already installed?** StackHand updates itself. Use StackHand › Check for Updates… to check now.

[Privacy policy](https://stackhand.netlify.app/privacy) · [Support](https://stackhand.netlify.app/support)

This repository holds release downloads only.
